Reading the results

EPS surprise compares verified, comparable actual and consensus EPS. A dash means unavailable or outside automatic EPS analysis—not zero. One-day returns use adjusted closes from the session before the reaction day to the reaction-day close.

After-close announcements use the next trading session. Intraday windows include pre-announcement trading. Divergence describes opposite EPS and one-day return signs; it does not establish causation. This is a selected historical sample, not an investment forecast.
